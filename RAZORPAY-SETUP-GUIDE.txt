✅ RAZORPAY INTEGRATION IS READY!
Now you just need to add your API keys.

──────────────────────────────────────────────────────────────
STEP 1: GET YOUR RAZORPAY API KEYS
──────────────────────────────────────────────────────────────

1. Go to: https://razorpay.com/
2. Sign up or Login
3. Go to: Dashboard → Settings → API Keys
4. Click "Generate Test Keys" (or use existing keys)
5. You'll see two keys:
   - Key ID (public): rzp_test_xxxxxxxxxxxxx
   - Key Secret (private): Keep it secret!

──────────────────────────────────────────────────────────────
STEP 2: ADD KEYS TO YOUR .env FILE
──────────────────────────────────────────────────────────────

1. Open the file: .env (in project root)

2. Add these lines at the end:

# Razorpay Configuration
VITE_RAZORPAY_KEY_ID=rzp_test_YOUR_KEY_ID_HERE
VITE_RAZORPAY_KEY_SECRET=YOUR_KEY_SECRET_HERE

3. Replace YOUR_KEY_ID_HERE and YOUR_KEY_SECRET_HERE with your actual keys

Example:
VITE_RAZORPAY_KEY_ID=rzp_test_9TpM2K7Lm3nOpQ
VITE_RAZORPAY_KEY_SECRET=abcdef123456789xyz

4. Save the file

──────────────────────────────────────────────────────────────
STEP 3: RESTART YOUR SERVER
──────────────────────────────────────────────────────────────

1. Stop your development server (press Ctrl+C)
2. Start it again: npm run dev

──────────────────────────────────────────────────────────────
STEP 4: TEST THE PAYMENT
──────────────────────────────────────────────────────────────

1. Go to POS page
2. Add items to cart
3. Click "Process Sale"
4. Select "Razorpay" payment method
5. Razorpay checkout will open
